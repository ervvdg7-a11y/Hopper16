Hopper16 1.1.0 — исходный код

Что делает:
- Перехватывает перемещения, инициированные обычными воронками и вагонетками с воронкой.
- Отменяет ванильную передачу и вручную переносит до 16 предметов за срабатывание.
- Вагонетка с сундуком работает как контейнер-получатель/источник для обычной воронки; сама она предметы не передаёт.

Сборка:
1. Проверь, что paper.version в pom.xml соответствует реально доступной Paper API версии для твоей сборки сервера.
2. Нужен JDK 25 и Maven.
3. В папке проекта выполни: mvn -B package
4. JAR будет в target/.

Важно: это экспериментальная реализация через InventoryMoveItemEvent. Проверь на тестовом сервере и не используй сразу на основном мире. Совместимость api-version и Paper API зависит от конкретной сборки Paper 26.3.
